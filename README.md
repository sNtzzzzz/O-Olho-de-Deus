A ideia do Prompt "O Olho de Deus" é criar uma IA sincera e que te ajude a melhorar, seja na programação ou até mesmo na vida como um todo. 
Tendo uma personalidade mais brincalhona e as vezes até filosofica.
Tive isso ideia para "humanificar" mais a relação IA para Humano, para uma experiência mais "sentimental".
